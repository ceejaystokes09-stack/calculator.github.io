# 🧮 Basic Web Calculator

A clean, responsive, and minimalist web calculator built with core front-end technologies. This project demonstrates foundational concepts in web development, DOM manipulation, event handling, and modern UI layout design.

## ✨ Features

- **Core Mathematical Operations:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Clean UI Layout:** Designed for clarity and ease of use with smooth button feedback.
- **Responsive Interface:** Formatted to work smoothly across desktop and mobile screens.
- **Fast & Lightweight:** Built using plain Vanilla JavaScript without external frameworks or dependencies.
